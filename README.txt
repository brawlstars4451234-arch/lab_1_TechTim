TechFix — учебный сайт для лабораторной работы.

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Файлы:
- index.html — структура сайта
- style.css — оформление и адаптивность
- script.js — меню и демонстрационная форма

Публикация через GitHub Pages:
1. Создайте репозиторий на GitHub.
2. Загрузите index.html, style.css, script.js.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку main и папку /(root).
5. Сохраните и дождитесь публикации.

Важно: форма на сайте демонстрационная и не отправляет данные на сервер. Почта hello@techfix.example — пример, замените её перед реальной публикацией.
